The funniest one-line warning label for a time machine — a straight-faced safety notice about the oldest hazard in time travel: meeting yourself. One line, 112 characters, inside the 120-character gate.

> WARNING: Do not meet yourself. If you do, do not shake hands — one of you is the spare, and neither knows which.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output npx tsx main.ts
```

This writes the label to `output/entry.txt` and self-checks the gate (single non-blank line, 1–120 characters).
